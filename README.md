# Jasorsi Ghosh — Personal Academic Website

Personal academic website designed with a classic Franco-Belgian comic aesthetic (Tintin, Asterix, Lucky Luke, The Smurfs, Spirou, Blake & Mortimer).

## 🚀 Quick GitHub Pages Deployment

1. **Upload to GitHub**:
   - Push all files (`index.html`, `.nojekyll`, and the `assets/` directory) to the root of your GitHub repository (e.g., `jasorsi13/jasorsi13.github.io` or repository branch).
2. **Enable GitHub Pages**:
   - Go to your repository **Settings** → **Pages**.
   - Under **Build and deployment** → **Source**, select **Deploy from a branch**.
   - Set Branch to `main` (or `gh-pages`), Folder to `/ (root)`, and click **Save**.
3. **Live URL**:
   - Your site will be live at `https://jasorsi13.github.io/` (or your custom domain).

## 📁 Repository Structure
- `index.html` — Main website page
- `.nojekyll` — Bypasses Jekyll processing for static asset rendering
- `assets/css/` — Styling and clear-line comic design system
- `assets/js/` — Standalone lightbox magnifier, modals, and vector character animations
- `assets/images/` — Public figures and images
- `assets/paper_img/` — Undergraduate research diagrams
